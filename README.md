## 三、技术说明

- 纯 HTML + CSS + Vanilla JS，**不引用任何外部 CDN**（无 Google Fonts、无 Tailwind CDN），国内外打开都稳。
- 询盘表单不依赖后端：填完点击按钮会打开 WhatsApp 并预填好姓名/公司/国家/产品/数量/需求，客户按发送即可。号码已按国际格式写入 `wa.me/8613682377128`。
- 全站响应式，已在 1440px 与 390px 两档实机验证。
- 每个产品链接带 `?product=xxx` 参数，从产品页点「Enquire」会自动选中对应产品。

**本地预览：**

```bash
cd jianai-rubber
python3 -m http.server 8099
# 打开 http://127.0.0.1:8099
```

## 四、必须由客户确认 / 补充的信息

站内文案的事实边界我做了严格控制：**只写了能确定的**（公司名、中文名、电话、深圳、6 款产品的外观与功能），凡是需要客户提供的数据一律没编。以下 9 项建议尽快补：

| # | 项目 | 站内现状 | 需要客户给 |
|---|---|---|---|
| 1 | 工厂详细地址 | 只写 “Shenzhen, Guangdong, China” | 具体到区/街道，用于信任度与地图 |
| 2 | 成立年份 / 厂房面积 / 员工数 / 月产能 | **未写**（不编数字） | 有数据可加进 `about.html` 的 Company facts |
| 3 | 认证（CE / RoHS / FDA / REACH / ISO9001 / BSCI 等） | **一个都没写** | 有证书才写，没证书不能写 |
| 4 | MOQ / 打样费 / 打样周期 / 大货交期 | 现为定性表述 | 给具体数字，转化率明显更高 |
| 5 | 主要出口市场 | 写 “Worldwide” | 可换成具体国家/区域 |
| 6 | 企业邮箱 + 域名 | **只有电话和 WhatsApp** | 建议注册域名 + 企业邮箱（如 sales@域名），我把表单改成邮件+WhatsApp 双通道 |
| 7 | 营业时间 | 暂写 Mon–Sat 09:00–18:00 (GMT+8) | 确认或改 |
| 8 | 车间 / 产线 / 仓库照片、证书图 | 未放 | B2B 买家必看，建议补 6–10 张 |
| 9 | 彩盒 / 套装包装实拍 | 未放 | 私标客户最关心这一块 |

> 另外，站内 “In-house molding”“Full inspection”“Confidentiality” 等属于**能力与流程描述**，请客户确认与工厂实际一致；如果某条做不到，告诉我我直接删或改。
